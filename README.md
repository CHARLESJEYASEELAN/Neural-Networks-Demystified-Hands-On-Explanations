# Neural Networks Demystified: Hands-On Explanations

Welcome to **Neural Networks Demystified**! This repository is a collection of educational Jupyter notebooks designed to help beginners and intermediate learners understand various neural network architectures. Each notebook focuses on the "why" behind choosing a specific network for a task, including short theory, real-world applications, a simple implementation (from dataset loading to evaluation), and step-by-step inferences explaining every decision.

## Why This Repo?
- **Educational Focus**: Emphasizes reasoning—why a network fits a task, why certain layers/optimizers/metrics are chosen, and why the results make sense.
- **Quick and Practical**: Each notebook is designed for fast implementation (under 30 minutes to code/review), using TensorFlow/Keras on small datasets.
- **Hands-On Learning**: Run the notebooks to experiment; great for self-study or as a reference.

## Notebooks


1. Perceptron_Explained.ipynb: Binary classification on Iris subset.
2. Feed_Forward_Explained.ipynb: Regression on California Housing.
3. Deep_Feed_Forward_Explained.ipynb: Multi-class classification on MNIST.
4. LSTM_Explained.ipynb: Sequence classification on IMDB sentiment.
5. GRU_Explained.ipynb: Time series prediction on synthetic sine wave.
6. Autoencoder_Explained.ipynb: Dimensionality reduction on MNIST.
7. Denoising Autoencoder: Image denoising on noisy MNIST.
8. Deep Convolutional Network: Image classification on MNIST/CIFAR-10 subset.
9. Deep Residual Network: Advanced image classification on CIFAR-10.
10. Attention Network: NLP seq2seq on toy data.

## How to Use
1. Clone the repo: `git clone https://github.com/yourusername/neural-networks-demystified.git`
2. Open in Jupyter: `jupyter notebook` or use VS Code/Colab.
3. Run each notebook—experiments are lightweight and should train quickly on standard hardware (e.g., RTX 4060).

## Requirements
- Python 3.8+
- TensorFlow 2.x
- NumPy, Matplotlib, Scikit-learn (for datasets and viz)
